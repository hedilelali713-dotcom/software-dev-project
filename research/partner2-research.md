# AI Coding Tools and Their Limitations

## What I researched

For my part, I looked at AI coding tools like GitHub Copilot and Cursor. These tools can help developers write code, understand programming problems, and find possible solutions.

One thing I found interesting is that AI can suggest code while someone is programming, which can save time on certain tasks.

But AI isn't always correct. Sometimes it gives code that has errors or doesn't work the way we want. That's why developers still need to test their code and understand what they're using.

## What I want to include in our video

I want to explain how tools like GitHub Copilot and Cursor are being used by developers.

I'll also talk about why we shouldn't completely depend on AI when programming.

## Research finding

The 2025 Stack Overflow Developer Survey found that more developers distrust the accuracy of AI tools than trust it. Around 46% of respondents said they distrust AI-generated results.

I think this is important because even though AI tools like GitHub Copilot and Cursor can help with coding, developers still need to check the code and test it themselves.

This shows that AI can be helpful, but it isn't something programmers should completely rely on.
