# How AI Is Being Used in Software Development

## What I researched

For my part, I looked into how AI is being used in programming today. I found that developers can use AI tools to help write code, explain errors, and come up with ideas when they're stuck.

AI can make some programming tasks easier, but developers still need to understand the code and check if it actually works.

## What I want to include in our video

I want to explain why AI is becoming more common in software development and introduce the question of whether it could replace developers.

I also want to mention that AI can help with coding, but it doesn't mean developers are no longer needed.
