# Partner 1 - Introduction

Hi everyone! Our topic today is: Will AI replace software developers?

AI has become a big part of technology, especially when it comes to programming. Tools like ChatGPT and GitHub Copilot can help developers write code, understand errors, and find solutions to problems.

According to the 2025 Stack Overflow Developer Survey, 84% of respondents were either using or planning to use AI tools in their development process.

That's a pretty big number, and it shows how common AI has become in programming.

But just because AI can help write code, does that mean it can actually replace developers?

To answer that, we first need to look at what these tools can do and where they still struggle.
