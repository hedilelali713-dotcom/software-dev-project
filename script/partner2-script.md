# Partner 2 - AI Coding Tools and Their Limitations

So, what can AI actually do for programmers?

There are tools like GitHub Copilot and Cursor that can suggest code, explain errors, and help developers complete certain tasks faster.

For example, if you're stuck on a programming problem, you can ask AI for help instead of spending a long time trying to figure it out.

But there's also a downside. AI doesn't always give the right answer, and sometimes the code it creates has mistakes.

According to the 2025 Stack Overflow Developer Survey, around 46% of respondents said they distrust the accuracy of AI tools.

This shows why developers still need to understand their code, test it, and make sure everything works properly.

So even though AI is useful, we shouldn't depend on it for everything.
